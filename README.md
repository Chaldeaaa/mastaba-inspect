# Inspect

[English](README.en.md)

手持武器时按 **G** 检视，可以边走边看。攻击、瞄准、切换装备或奔跑会中断动作。

支持 **Mastaba R66**、**Mastaba Fixed Blade** 和 **WOX Compact**。

安装 [BepInEx](https://thunderstore.io/c/gtfo/p/BepInEx/BepInExPack_GTFO/) 后，把 [MastabaInspect.dll](plugin/MastabaInspect.dll?raw=true) 放入当前游戏配置的 `BepInEx/plugins/MastabaInspect/` 文件夹，再启动游戏。更新时替换旧 DLL；如果装过独立的 R66Inspect，请先停用它。

配套皮肤：[Mastaba R66](https://github.com/Chaldeaaa/endfield-r66) · [Mastaba Fixed Blade](https://github.com/Chaldeaaa/endfield-knife)。

鸣谢：[BepInEx](https://github.com/BepInEx/BepInEx)、[Harmony](https://github.com/pardeike/Harmony) 和 [Il2CppInterop](https://github.com/BepInEx/Il2CppInterop)；[大墨迹自己玩](https://space.bilibili.com/309259886) 的 [Endfield HELGun](https://thunderstore.io/c/gtfo/p/DaMoJi/Endfield_HELGun/) 为配套皮肤提供了视觉参考。
