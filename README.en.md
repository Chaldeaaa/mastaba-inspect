# Mastaba Inspect

[简体中文](README.md)

Press **G** to inspect your weapon, including while walking. Attacking, aiming, switching weapons or sprinting interrupts the animation.

Supports **Mastaba R66**, **Mastaba Fixed Blade** and **WOX Compact**.

Install [BepInEx](https://thunderstore.io/c/gtfo/p/BepInEx/BepInExPack_GTFO/), put [MastabaInspect.dll](plugin/MastabaInspect.dll?raw=true) in your active game profile's `BepInEx/plugins/MastabaInspect/` folder, then launch the game. Replace the old DLL when updating; disable the standalone R66Inspect plugin if installed.

Matching skins: [Mastaba R66](https://github.com/Chaldeaaa/endfield-r66) · [Mastaba Fixed Blade](https://github.com/Chaldeaaa/endfield-knife).
